## 채우기 규칙
1. **가격($):** 대표 아이템 실제 가격대를 KRW 확인 후 $ 환산.
2. **Tax refund:** 매장 'Tax Free' 스티커 + 직원 확인. ✅ instant / ✈️ airport only / none.
3. **Hours:** 구글맵·매장 안내판 실측.
4. **One-liner:** "왜 가야 하나" 한 줄. 과장 금지.
5. 영상 1편 리서치 → 5~8개 행 채움 → 8주면 50곳 완성.
